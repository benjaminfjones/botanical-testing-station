# botanical-testing-station

> "His Imperial Majesty's Desert Botanical Testing Station" -- Frank Herbert

A personal website / blog combo powered by [Marmite](https://github.com/rochacbruno/marmite)

## Notes

- if publishing to `public/` in the project root, marmite watch mode will go crazy loops
- make sure the full site URL is in `marmite.yaml` otherwise all the content is assumed to
  be at the root of the site
